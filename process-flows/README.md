# End-to-End Process Flows

Business-process flow documentation for the integrated SAP implementation.

Planned flows:

- Procure-to-Pay (P2P / S2P)
- Order-to-Cash (O2C / L2C)
- Record-to-Report (R2R)
- Plan-to-Produce (P2P / D2O)

Each flow should show business steps, responsible organizational units, SAP transactions/apps, master-data dependencies, and FI/CO integration points.
