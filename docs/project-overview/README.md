# Project Overview

This section contains the business context, implementation methodology, scope, milestones, and project governance for the TechNova Manufacturing GmbH SAP S/4HANA implementation.

## Implementation Philosophy

The project is documented as an integrated business-process implementation. Configuration decisions are recorded together with organizational dependencies, validation evidence, transport/change-control information, and downstream integration impacts.

## Core Business Processes

- Record-to-Report (R2R)
- Source-to-Pay (S2P)
- Design-to-Operate (D2O)
- Lead-to-Cash (L2C)
- Service

See the root README for the current implementation status and overall roadmap.
