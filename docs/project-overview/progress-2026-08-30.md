## 1. CO & Universal Journal Configuration

### 1.1 CO Version-to-Ledger Alignment

A system-wide financial customizing consistency check using `FINS_CUST_CONS_CHK` identified the following blocking condition:

```text
The version 0 of CO area 9000 is not assigned to any ledger
```

The issue was traced to the Controlling version not being assigned to the corresponding S/4HANA ledger structure.

**Resolution:**

- IMG area: `Controlling → General Controlling → Organization → Define Ledger for CO Version`
- Configuration table: `FINSC_CMP_VERSNC`
- Controlling Area: `9000`
- CO Version: `0`
- Ledger: `0L` — Leading Ledger / Legal Valuation

The configuration was persisted and the blocking consistency-check error was cleared.

### 1.2 Mass Data Project `PRJ_9000` — Cockpit B2K

A subsequent posting simulation using `FINS_CUST_CONS_CHK_P` identified another prerequisite:

```text
Mass data project PRJ_9000 not yet completed: Posting is not allowed (9000 / 0L)
```

The issue was addressed through the S/4HANA subsequent-assignment/mass-data update process.

**Execution:**

- IMG area: `Controlling → General Controlling → Organization → Subsequent Assignment of Company Codes → Run Project for Updating Existing Journal Entries`
- Mass Data Project: `PRJ_9000`
- Activity: `B2K` — Assign Company Code to Controlling Area

**Result:** The background processing completed successfully across the assigned data packages with **0 errors / 0 warnings**. The posting block for Company Code `9000` / Ledger `0L` was removed.
